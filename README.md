# LearningPlayWright

A small Playwright learning project containing example scripts and JavaScript concepts.

## Project Structure

- `chapter_01_Basics/` - Basic Playwright scripts and learning notes
- `chapter_02_js_concepts/` - JavaScript concept examples and practice files

## Getting Started

1. Install dependencies (if you add a `package.json` later):
   ```bash
   npm install
   ```

2. Run Playwright tests (after setup):
   ```bash
   npx playwright test
   ```
